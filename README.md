🌸 Quote Generator

A simple ReactJS project that generates random motivational quotes using a public API.

## 📌 About the Project

This project was created as part of a ReactJS and AJAX assignment.

The application uses ReactJS concepts such as components, JSX, props, state, and event handling. It also uses the JavaScript `fetch()` method to get random quotes from a public API.

## ✨ Features

* Random quote generator
* Public API integration
* React components
* JSX
* Props
* State management
* Button event handling
* Responsive and clean user interface

## 🛠️ Technologies Used

* ReactJS
* JavaScript
* HTML
* CSS
* Vite
* REST API

## 🌐 API Used

DummyJSON Quotes API:

`https://dummyjson.com/quotes/random`

## 🚀 How to Run

1. Clone the repository.

2. Open the project folder in VS Code.

3. Open the terminal.

4. Install dependencies:

```bash
npm install
```

5. Start the development server:

```bash
npm run dev
```

6. Open the local URL shown in the terminal.

## 📚 React Concepts Demonstrated

### Components

The project uses separate React components such as `App` and `QuoteCard`.

### JSX

JSX is used to create the user interface.

### Props

The quote and author are passed from `App` to `QuoteCard` using props.

### State

React `useState()` is used to store the quote, author, loading status, and error message.

### Event Handling

The `onClick` event is used to fetch a new quote when the button is clicked.

### AJAX / API

The `fetch()` method is used to request quote data from the public API.
